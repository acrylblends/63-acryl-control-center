First start: on macOS the app is not signed yet, so right-click it and choose Open. On Windows, if SmartScreen asks, click More info and then
Run anyway. On Linux, double-click the .deb file to open it in the Software app.

This repository holds only the releases. The source is in the ACRYL monorepo:
[acryldev/acryl/apps/acryl-control-center](https://github.com/acryldev/acryl/tree/main/apps/acryl-control-center), released there under the tags `control-center-v*`. ACRYL Control Center is also a Blend in
the registry: [acrylblends.github.io](https://acrylblends.github.io/blends/software-marketplaces/agentic-app-marketplaces/acryl.control-center).
